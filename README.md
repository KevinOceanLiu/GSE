## 1. Data

### `data/data.csv`

Analysis-ready dataset used for model fitting and validation.

Main columns include:

- `ID`
- `richness`
- `longitude`, `latitude`
- explanatory variables:
  - `Short.wave`
  - `Wind.speed`
  - `Soil.depth`
  - `Soil.total.nitrogen`
  - `Soil.pH`
  - `Soil.CEC`
  - `Elevation`
  - `Slope`
  - `sinAspect`
  - `cosAspect`
  - `Distance.to.artificial.land`
  - `Distance.to.water`

### `data/data3_partitions.csv`

Analysis-ready dataset with additional stratification labels used for the sensitivity analysis in Figure 10.

Additional columns include:

- `Elevation Division`
- `richness Division`
- `area Division`

### `data/boundary/`

Study-area boundary shapefile used for the regular square-grid and hexagonal-grid sensitivity analyses.

Required shapefile components include:

- `boundary.shp`
- `boundary.shx`
- `boundary.dbf`
- `boundary.prj`
- `boundary.cpg`

## 2. Result files

### `result/*_test_residuals.csv`

Test-set residual files for the nine predictive models:

- `lm`
- `rf`
- `xgbTree`
- `gbm`
- `knn`
- `gam`
- `gwr`
- `svmRadial`
- `cubist`

These files contain model predictions and residuals on the common holdout test set.

### `result/GSE_results_kNN2.csv`

GSE values across candidate k-nearest-neighbor neighborhood sizes for all nine models.

### `result/rf_local_error_variance_richness.csv`

Local error variance and observed richness data for the random forest model, used to examine the relationship between species richness and local predictive instability.

Other result files can be regenerated by running the scripts below.

## 3. R scripts

### `model_training_and_residuals.R`

Fits the eight non-spatial predictive models:

- `lm`
- `rf`
- `xgbTree`
- `gbm`
- `knn`
- `gam`
- `svmRadial`
- `cubist`

The script performs the fixed 70/30 train-test split, applies 5-fold cross-validation within the training set, and exports test-set predictions, residuals, model performance metrics, and scatterplots.

### `gwr_model_residuals.R`

Fits geographically weighted regression (GWR) as the spatially explicit model. The script uses a fixed adaptive bandwidth of 227, calculates predictions from local coefficients, and exports GWR test-set residuals and model performance metrics.

### `calculate_GSE_knn.R`

Calculates k-NN-based GSE values for all models across the candidate K values and exports `GSE_results_kNN2.csv`.

### `calculate_GSEopt_by_model.R`

Uses the GSE–K results to fit LOESS curves, calculate marginal rates of change, identify model-specific optimal K values, and generate the GSEopt curve figure.

The optimal K rule is defined as the first K at which three consecutive marginal-rate values are greater than −1%.

### `permutation_validation.R`

Performs permutation validation by randomly reassigning residuals to test locations while preserving the residual magnitude distribution. This script exports the observed GSE, mean permuted GSE, ΔGSE, and permutation p-value for each model.

### `global_morans_I.R`

Calculates Global Moran’s I for test-set residuals of all nine models using the same model-specific optimal K values as in the GSE analysis.

### `stratified_sensitivity_analysis.R`

Calculates RMSE and GSEopt under three stratification schemes:

- geographical area
- observed species richness
- elevation

The output is used for the stratified sensitivity analysis shown in Figure 10.

### `grid_sensitivity_analysis.R`

Calculates GSE under regular square-grid and hexagonal-grid neighborhood definitions across multiple grid sizes. This script is used to compare adaptive k-NN neighborhoods with non-adaptive grid-based spatial units.

### `runtime_comparison.R`

Compares the runtime of RMSE, fixed-K GSE, and the full GSEopt procedure using the random forest residuals from the independent test set.

## 4. Suggested running order

Please set the working directory to the repository root before running the scripts.

```r
setwd("path/to/GSE_repository")
```

Suggested order:

1. `model_training_and_residuals.R`
2. `gwr_model_residuals.R`
3. `calculate_GSE_knn.R`
4. `calculate_GSEopt_by_model.R`
5. `permutation_validation.R`
6. `global_morans_I.R`
7. `stratified_sensitivity_analysis.R`
8. `grid_sensitivity_analysis.R`
9. `runtime_comparison.R`

The repository also includes precomputed residual and GSE result files in the `result/` folder. Therefore, users may start from `calculate_GSE_knn.R` or later scripts if they do not need to refit the models.

## 5. Reproducibility notes

- All scripts use a fixed random seed: `set.seed(123)`.
- The dataset is sorted by `ID` before splitting to ensure stable results regardless of row order.
- A fixed 70/30 train-test split is used.
- Five-fold cross-validation is applied within the training set for model fitting.
- GSE is calculated on the common holdout test set.
- GWR uses a fixed adaptive bandwidth of 227.
- Spatial cross-validation was not used in this study.
